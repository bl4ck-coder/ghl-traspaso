# Writing a page through GHL's internal editor API (route used for ADICIO)

Only with Nacho's explicit OK (terms risk, see SKILL.md). Working scripts: `base-2026-11-18/40-adicio-ghl-api/herr/`. Starting code: `NickBhai-GH/ghl-internal-api` (MIT), copied as `funnel_page_builder.py`.

## Procedure
1. **Session.** He logs in (visible Chromium on :9333, see SKILL.md). Read the Firebase token from IndexedDB `firebaseLocalStorageDb` inside the page and keep it in a private scratch file; never print it. Re-read it before each write: it expires within the hour.
2. **Read first.** GET the page data and save it (`datos/get-data.json`, `leer_guardado.js`). Take element templates from GHL's own saved elements (`plantillas-reales.json`), not from guesses: section/row/column/element `metaData`, `extra`, `customClass`.
3. **Build from the approved source, not from screenshots.** Map each `data-ghl` node of `importar.html` to section → row → column → element (`armar_home.py`, then `armar_contacto.py`, `armar_resto.py` per group of sections). Carry the original CSS rules compiled per section (`compilar_portada.py`, tinycss2) plus small «puentes» CSS for GHL's extra `.inner` boxes; never rebuild styles from two computed snapshots.
4. **Write a draft only.** `subir.py` autosaves into the draft page (never publish). Write one or two sections first, compare, then the rest in batches. Before writing, close/leave the editor tab on that page so its autosave does not overwrite yours.
5. **Page-level code through the editor UI.** Use the editor's own Custom CSS, Body, SEO and schema fields. Mark each block. For a Body upgrade, back up the field and use `guardar_body_ui.py NEW.js --marca 'NEW TAG' --reemplazar OLD.js --respaldo BACKUP` (use helpers only on their configured draft). Require exactly one match on the old source; replace it in place so script order, guards and unrelated blocks stay intact. After save, reopen the field (`leer_body_ui.py`) and assert one exact new block, no old block and the unrelated blocks intact. Appending a second animation layer can leave the old one active behind its singleton guard.
6. **Reproduce and verify on the affected surface.**
   - For editing-canvas defects, inspect its DOM and computed styles before copying CSS from the preview. The canvas may use `button` instead of `a` and TipTap wrappers instead of `.text-output`. If text collapses or controls collide, measure column widths, intersections and `container-type`; inline-size containment can collapse auto-width columns. Compile a bridge scoped to the measured editor root (e.g. `@scope (#page-creator .previewer)`), preserving the native blocks. Use `armar_editor_paridad.py` and `verificar_editor_paridad.py --css FILE.css` as the recipe: run against the baseline, test injected CSS, then save and rerun without injection. Capture from the top-level tab after scrolling the iframe.
   - **Prove native editing with a reversible change.** In the authorized draft, record the exact original text, edit one representative native heading through the editor, blur it, and give the editor time to commit the change before clicking Save; saving in the same operation as blur can leave the previous value saved. Check the exact temporary value in a fresh preview and after reopening the editor. Restore the exact original even if a check fails, then verify it in both places after reopening. Check that the animation hook and SEO data survive the cycle.
   - For visitor defects, test patches in memory with Playwright, then rerun against the saved draft URL without injection. Match elements by stable classes and assert counts before comparing; measure positions relative to the section so drift in an earlier section does not masquerade as a local defect. Scroll targets into view with `scrollIntoView({block:'center',behavior:'instant'})`, await `document.fonts.ready` and `img.decode()` where relevant, then inspect the actual capture for text wrapping and painted images. If the boxes match but the text differs, inspect line rectangles and the painted font (`CSS.getPlatformFontsForNode` in Chromium), not just the computed family name. Check overflow, errors, expected SEO, and the interactions that changed. Test the editor separately even when the preview passes. Skip changes that do not improve a measured defect.

## Pitfalls
- **Keep `schemaMarkupId` when autosaving.** The schema hangs off each page version; an autosave without it drops the schema. Copy it from the newest history entry by date, not the last array item.
- **The schema JSON view replaces the whole set** and needs the `<script type="application/ld+json">` wrapper with `@graph`; paste every node each time (details in `builder-facts.md`).
- **A native Form element with empty `formId` renders nothing.** Create the form by API (copy an existing form's shape, only the needed fields) and set its id on the element.
- **In the editor a form renders inside an iframe**, so page CSS never reaches it. Reuse the form already attached to the draft; `POST /forms/{id}` with `{name, formData}` updates it (PUT/PATCH returned 404). In ADICIO, `customStyle` alone lost to native rules. Append the scoped override to `formData.form.fieldCSS`, preserving all fields, first prove the result by temporary injection in the real widget, then read the stored CSS back exactly and measure the loaded iframe at the canvas widths. The open editor can cache an old widget even after a normal reload: compare the exact iframe URL in a fresh browser, then hard-reload the editor before diagnosing. Recipe: `estilar_form_borrador.py`, `verificar_suscripcion_iframe.py`.
- **Responsive editor presets resize a canvas, not the actual CSS viewport.** Read `.previewer` width and computed media rules before claiming the mobile editor is good. Compile page width media rules into named container queries scoped to `#page-creator .previewer`; retain viewport rules for the public preview. Confirm with the editor's own desktop/tablet/mobile presets, using computed bounds for buttons, text and form. A tablet scroll bar can come from GHL resize handles outside a correctly sized page; measure actual controls before clipping the editor.
- Synthetic `.click()` often fails on editor dialogs and collapses; dispatch real CDP mouse events at the element's coordinates.
- GHL wraps each row/column in `.inner{max-width:1170px}` and adds its own paddings/margins; `allowRowMaxWidth: true` lets a row go full width. Expect to neutralise these per section in the bridge CSS.
- Fonts: list the page fonts in the page's font settings (`fontsToLoad`) so the preview loads them; otherwise text falls back to Times.
